# Taira 下載與更新

Taira 可以透過手機、平板或另一台電腦遠端操作自己的 Mac／Windows 電腦。

目前版本：1.2.88

## 下載

- Windows 11（64 位元）：[下載 TairaSetup.msi](https://raw.githubusercontent.com/martinhuang2024/Taira-Releases/main/TairaSetup.msi)
- Mac（Apple 晶片、macOS 14 或更新版本）：[下載 Taira.dmg](https://raw.githubusercontent.com/martinhuang2024/Taira-Releases/main/Taira.dmg)

已安裝 Taira 的話，可以直接在程式裡按「檢查更新」。

## 1.2.88 更新內容

- 整理過長的設定頁：常用的遠端螢幕、畫面方案、隱私遮罩和聲音，現在更容易找到。
- 「畫面方案」可選自動、流暢優先或畫質優先，不用分別調整 FPS、解析度和編碼。
- 原本的進階畫面設定、Passkey、鍵盤、檔案傳輸及連線診斷沒有刪除，只是收進可展開的分類。
- 更新不會覆蓋先前自訂的畫質與登入資料，舊設定會標示為「自訂」。

## 之前的更新

### 1.2.87

- 「畫面設定」新增「畫面延遲」，可以選擇「最低延遲」或「平衡」；平衡模式較適合畫面偶爾抖動的情況。
- 「連線資訊」增加畫面解碼和顯示等待的診斷資料，方便查找卡頓原因（依瀏覽器支援程度顯示）。
- 不需要重新設定 Passkey、驗證碼或畫質。可以直接切換兩種模式，比較哪一種在手機上更順。

### 1.2.86

- 改善連線偶爾卡頓的問題，避免重複指令讓畫面不必要地重新載入。
- 短暫斷線時會更快嘗試恢復；如果電腦暫時離線，會逐步延長重試間隔。
- 「畫面設定 → 連線資訊」新增等待時間、重連次數和畫面切換資訊，更容易查找延遲原因。
- 原本的 Passkey、畫質設定都會保留，不需要重新設定。

### 1.2.85

- Passkey 登入現在收在「進階」裡，登入畫面更簡潔。
- 點開「進階」就能使用 Passkey；按鈕改成紫色，和「連線」更容易區分。
- 六位數驗證碼與原本的 Passkey 都能照常使用，不需要重新設定。

### 1.2.84

- 改善遠端畫面傳送時的資料處理，減少不必要的等待和重複處理。
- 針對畫面快速變動可能出現的卡頓進行優化，實際改善幅度會依裝置與網路狀況而異。
- 原本的連線方式、畫質設定和 Passkey 都會保留，不需要重新設定。

### 1.2.83

- 修正撤銷裝置後，「未知」裝置又出現在清單中的問題。
- 裝置清單只會顯示仍有登入授權的裝置，不再顯示過期的舊紀錄。
- 原本的 Passkey、驗證碼和正常登入裝置都會保留，不需要重新設定。

### 1.2.82

- Mac 版本調整了程式啟動、更新和隱私遮罩的內部運作方式，讓後續維護更容易。
- 保留原本的遠端連線與操作方式，不需要重新設定 Passkey 或六位數動態碼。
- Windows 也同步更新版本，使用方式不變。

提醒：這次主要是 Mac 內部功能調整。更新後建議試試啟動、檢查更新，以及隱私遮罩是否正常。如果遇到問題，請提供畫面或診斷紀錄。

## 之前的更新

### 1.2.81

- 安全設定更集中：現在打開「重設安全設定」，就能選擇「建立 Passkey QR」或「重設全部驗證設定」。
- 「已驗證裝置」改名為「撤銷已驗證裝置」，可以選擇要登出的裝置。
- 原本的 Passkey、六位數動態碼和已登入裝置都會保留，不需要重新設定。

提醒：只有選擇「重設全部驗證設定」並再次確認，才會清除原有設定。

### 1.2.80
- 第一次使用時，可以從電腦產生 Passkey QR，拿手機掃描並建立 Passkey。
- QR 有效時間為 2 分鐘，掃碼後還是需要完成手機上的驗證。
- Mac 設定畫面調整得更清楚，現在需要 macOS 14 或更新版本。

### 1.2.79
- 改善重新整理時短暫跳出驗證畫面，以及更新前後需要重複輸入驗證碼的問題。
- 登入可以直接選擇六位數動態碼或 Passkey，不必先設定「信任此裝置」。
- 簡化重複的安全和畫面設定，並加入逐台撤銷裝置的功能。

### 1.2.78
- 改善手機上安全設定按鈕太擠、文字換行不整齊的問題。

### 1.2.77
- 初次加入 Passkey 登入功能，支援 Bitwarden 與裝置內建的 Passkey。

### 1.2.76
- 加入已授權裝置的管理與撤銷功能。後續版本已進一步簡化登入流程。

### 1.2.75
- 改善手機畫面填滿與比例顯示；後續版本已改為自適應畫面。

### 1.2.74
- 驗證碼輸入錯誤時會自動清空，方便重新輸入。
- 改善 iPhone 小螢幕上方的顯示空間。

### 1.2.73／1.2.72
- 改善快速移動遠端畫面時容易卡頓、畫質突然下降的情況。
- 增加連線診斷資訊，方便查找延遲原因。

### 1.2.71
- 雙指可以自由放大；縮小時不會小於螢幕適配大小。

### 1.2.70
- 修正 iPad 上遠端桌面過小、黑邊過大的問題。

### 1.2.69
- 調整畫質與流暢度選項，讓不同網路環境下的遠端畫面更穩定。

如需使用 Passkey QR 首次設定，請先確認電腦與手機都已連線至 Tailscale。選擇 QR 註冊後，必須在手機上完成 Passkey 建立，掃碼本身不會直接登入遠端桌面。
